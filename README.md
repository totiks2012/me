### `me_lib/cit` — кардинальное обновление

**Что это:** снепшот-версионирование файлов. `cit` хранит слепки файлов в `.cit/` рядом с проектом, позволяет откатываться, просматривать diff, удалять в корзину. Не требует git.

Размер вырос с 364 до 466 строк.

**Формат снепшотов:**
- Было: `2026-07-26_19-10-50.cit`
- Стало: `cit__26-07-2026_19-10-50.cit` (имя файла + европейский формат даты)

**Флаг `-f` (finalize):** сборка полного ченджлога из всех снепшотов. Собирает все `.log`-записи, инжектит их в хэдер скрипта (после shebang), сохраняет оригинал. Параллельно создаёт `-F` копию с отдельным `.log`-файлом. Нужен для фиксации версии перед релизом.

```
me_lib/cit -f   # Выбрать файл → собрать ченджлог → -F копия
```

**`inject_changelog`:** при снепшоте shebang-файла ченджлог автоматически вставляется в хэдер снепшота.

**Новое меню:** «Восстановить из корзины» — поштучный выбор удалённых снепшотов, возврат в основное хранилище.

**`list_tracked/list_trashed`:** пути теперь выводятся с ведущим `/` (было `$PWD/...`).

**`cit.WIP`** — удалён. Его незавершённый функционал (finalize) реализован через `-f`.

me int — интерактивный выбор команд
Что изменилось

Раньше me int использовал TIOCSTI (инжекция в буфер ввода ядра). На современных ядрах Linux (Debian 13+) этот ioctl блокирован — команда не попадала на промпт, а падала в никуда.
Как работает сейчас

me int выводит выбранную команду в историю bash через history -s. После выбора команда печатается в терминал, добавляется в историю — жми Up ↑ (один раз), чтобы увидеть её на промпте, отредактировать и выполнить.

$ me int                  # → fzf выбор
me vol up                 # команда в истории
$ ↑ (один раз)              # → me vol up на промпте, редактируешь

Почему не TIOCSTI

TIOCSTI — не портируемый хак, работающий только на старых ядрах без ограничений. history -s — стандартный механизм bash, работающий везде, где есть bash.
Почему не READLINE_LINE

READLINE_LINE работает только внутри bind -x (keybinding), а не в обычной функции. Обёртка me() в me.completion перехватывает me int, но не может вставить текст на промпт из функции верхнего уровня. history -s — единственный надёжный способ без TIOCSTI и keybinding.

# Это блок описания самой утилиты

Алиасы в .bashrc работают, пока их 5–10. Когда их становится 30+:
Проблема 	Суть
Свалка 	Трудно найти нужную команду
Нет документации 	Через месяц забываешь флаги
Конфликты имён 	Последний алиас перезаписывает первый
Нет аргументов 	alias backup='tar -czf' — нельзя передать путь в середину
Всё в одной куче 	Не сгруппировать по темам (медиа/система/dev)
Нет поиска 	Только grep alias ~/.bashrc
Не работают в скриптах 	Алиасы не видны в неинтерактивном bash

Алиас — это тупая текстовая подстановка. В нём нет:

    проверки существования команды
    обработки ошибок
    валидации аргументов
    кодов возврата
    ветвлений

Решение: me

me — скрипт ($HOME/.local/bin/me) + конфиг (~/.config/me/me.conf). В конфиге описываешь методы с мета-тегами, вызываешь их одной командой.

# Было
aria2c --seed-time=0 --max-connection-per-server=16 --split=16 --continue=true --file-allocation=none --allow-overwrite=true --dir=/mnt/downloads "magnet:?xt=urn:btih:..."

# Стало
me tor add "magnet:?xt=urn:btih:..."

Как это работает

При вызове me <команда> скрипт:

    Ищет функцию me_method_<команда>() в me.conf
    Проверяет синтаксис через bash -n
    Загружает и выполняет
    Кэширует в /dev/shm/me_$USER/ — при повторном вызове грузится быстрее

Если конфиг изменился — кэш пересобирается автоматически.
Синтаксис метода

#@method: <имя>
#@description: <описание>
#@example: me <имя> [аргументы]
me_method_<имя>() {
    # bash-код
}

Пример:

#@method: pause
#@description: Поставить воспроизведение на паузу
#@example: me pause
me_method_pause() {
    playerctl pause 2>/dev/null || true
}

Примеры из практики

1. Управление музыкой

Было:

busctl --user call org.mpris.MediaPlayer2.mpv /org/mpris/MediaPlayer2 org.mpris.MediaPlayer2.Player Pause

Стало:

me toggle

2. Поиск по конфигам

Было:

find ~/.config -type f -name "*.conf" -exec grep --color=always -C2 "server" {} \; | less -R

Стало:

me fi -c "server" ~/.config

3. Бэкап с уведомлением

me backup

так же в методах его нет, приводится как идея пример

4. Массовый перезапуск Docker-контейнеров

me docker restart prod

в методах его нет приводится как идея пример
Интерактивный режим

me int

Открывает fzf со списком всех методов и описаниями. Выбрал — команда в истории, жми ↑ и выполняй.
Сравнение: алиас vs функция vs me-метод
Характеристика 	Алиас 	Bash-функция 	me-метод
Документация 	Нет 	Комментарии 	Мета-теги + автоподсказка
Аргументы 	Только хвост 	Полные $@ 	Полные $@
Ветвления 	Нет 	Да 	Да
Справка 	grep 	declare -f 	me -m метод
Поиск команд 	Вручную 	Вручную 	me — готовый список
Централизация 	~/.bashrc 	Любой файл 	Один me.conf
Группировка 	Нет 	Нет 	По темам
Обработка ошибок 	Нет 	return 	return + уведомления
Когда me нужен

    Администрируешь Live-системы (MiniOS, Puppy Linux) или несколько машин
    Вешаешь bash-скрипты на горячие клавиши оконного менеджера (i3/sway/bspwm)
    Нужен интерактивный выбор команд через fzf
    Хочешь держать .bashrc чистым

Когда me не нужен

    У тебя 3–5 алиасов
    Не хочешь централизовать управление

Установка

Скрипт me — в ~/.local/bin/me. Конфиг me.conf — в ~/.config/me/me.conf. Для настройки PATH запусти install_me.sh.

Зависимости для некоторых методов: playerctl, ripgrep, socat (для mpv), fzf.
