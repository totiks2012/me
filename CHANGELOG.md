## me_8_10_26
## ## 🚀 Release Notes / Что нового в версии 2.0

Произведён кардинальный рефакторинг архитектуры `me`. Движок полностью переведён на декларативную схему **Zero-Eval / Direct Execution**.

### 🏗️ Архитектурные изменения
* **Полный отказ от `eval`:** Движок больше не загружает BASH-код методов в текущую сессию и не генерирует временные файлы функций в кэше. Это полностью исключает риски синтаксических сбоев при работе со сложными кавычками, heredoc и экранированием.
* **Чистый декларативный `me.conf`:** Конфигурационный файл больше не содержит исполняемого кода (`me_method_*()`). Теперь это строгий манифест метаданных с явным указанием пути к скрипту через тег `#@script: me_lib/<script>.sh`.
* **Прямой диспетчер:** Движок моментально резолвит путь к скрипту и запускает его в отдельном субпроцессе. Изменение конкретного метода больше не требует сброса кэша и не влияет на остальные модули.
* **Мгновенный отклик:** Накладные расходы на вызов минимальны — резолвинг пути происходит за один проход `awk` по манифесту.

### `me net` — диагностика причин пропажи сети (`me_lib/net.sh`) (11_08_26)
Последовательная проверка по цепочке (NetworkManager → активные соединения → состояние интерфейсов → IP → маршрут по умолчанию → шлюз ping → интернет ping 1.1.1.1 → DNS → Wi-Fi сигнал). Каждая проблема выводится в формате «Причина → Исправить», первая найденная фиксируется как главная причина. С fzf — список проблем с превью (детали + совет), без fzf — текстовый вывод. В конце — итог: работает / частично / полностью недоступна.

### `me netre [soft|hard]` — перезапуск сети (`me_lib/netre.sh`) (11_08_26)
- `soft` (по умолчанию): `nmcli networking off → on` — мягкий перезапуск без прав root.
- `hard`: `systemctl restart NetworkManager` (sudo, если не root) — жёсткий перезапуск.
После перезапуска — опрос до подъёма сети (до ~20с) и краткий статус: интерфейсы, активные соединения, доступность интернета.

- **yfe.sh**: качество стрима YouTube 360p → 720p:
  - **Причина**: `yt-dlp -g -f "best[height<=720]" | mpv` — селектор `best` предпочитал готовые combined-форматы (360p, формат 18) и молча игнорировал качественный 720p DASH (video-only).
  - **`pick_fmt()`** — определяет формат по фактической доступности: проверка `bestvideo[height=720]/best[height=720]` (video-only 720p или combined как запасной); 720p доступен → `bestvideo[height<=720]+bestaudio/best[height<=720]`; недоступен → уведомление «720p недоступен — отдаю 480p» + `bestvideo[height<=480]+bestaudio/best[height<=480]`.
  - **Стрим переведён с pipe на mpv-native**: `mpv --ytdl-format="$(pick_fmt "$chosen")" "$chosen"` — mpv сам склеивает видео+аудио потоки через встроенный yt-dlp (EDL), т.к. `bestvideo+bestaudio` через `-g` даёт два URL, которые `--playlist=-` не сшивает.
  - **Баг-фикс по ходу**: первоначальная проверка `best[height=720]` (combined-формат ровно 720p) почти не существует на YouTube → почти всегда ложно «720p недоступен». Заменена на `bestvideo[height=720]/best[height=720]`.
    
- **me** (движок, vs. `me` из `me-main` 11_08_2026): удалён наивный awk-парсер в `load_method()` — вместо него гибридный кэш + бронебойный экстрактор:
  - **`extract_method_body()`** — посимвольная state machine: одинарные/двойные/ANSI-C кавычки, backtick, heredoc (`<<`, `<<-`, `<<'EOF'`), арифметика `((...))`/`$((...))`, комментарии; `bash -n` как арбитр границы (append-refine, если скобка преждевременная).
  - **`load_method_source()`** — источник тела: готовый файл кэша → пересборка кэша → fallback на экстрактор.
  - **Гибридный кэш `/dev/shm/me_$USER/methods/`**: файлы `me_method_<name>.sh` + `.hash` (md5-гейт), атомарная пересборка tmp+mv, `method_cache_ok()`/`build_method_cache()`.
  - **`me cache-rebuild`** — принудительная пересборка кэша.
  - **`me int`** — 3 поля → 4 поля `команда|категория|описание|пример`, парсинг `[cat: X]` из описания, fzf `--with-nth=1,2` (показ категории), preview с категорией/описанием/примером, F5 → `int_help.sh {1}` (метод), текстовый fallback с категорией.
  - **Фикс вариантов `#@variants:`** — срез комментария по regex `[ \t]+# ` вместо литерала `"  # "` (работает и с одним пробелом перед `#`).

- **gifx.sh**: миграция конфига в `~/.config/me/gifx.conf` (fallback на старый путь), мгновенная остановка ffmpeg по Escape (`kill -INT` + `wait`), таймаут `read` 0.3→0.05, убран `2>/dev/null` у GIF-конвертации (ошибки видны).
